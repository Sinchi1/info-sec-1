# Лабораторная №1. Защищённый REST API

Java 21, Spring Boot, Spring Security, Lombok, H2 в памяти. Приложение регистрирует пользователей, выдаёт JWT и возвращает личные заметки.

## API

Запуск из корня проекта: `.\mvnw.cmd spring-boot:run`. Настройки — в `src/main/resources/application.yaml`.

| Метод | Тело запроса | Результат |
|---|---|---|
| `POST /auth/register` | `{"login":"alice","password":"Strong-password-2026!"}` | `201`, логин; при повторе — `409` |
| `POST /auth/login` | Те же логин и пароль | `200`, `accessToken`, `tokenType`, `expiresIn`; неверный пароль — `401` |
| `GET /api/data` | Без тела; заголовок `Authorization: Bearer <токен>` | `200`, список заметок; без токена — `401` |

## Меры защиты

- **SQLi:** все запросы `JdbcTemplate` используют `?` и отдельные параметры. Логин и другие значения не подставляются в SQL конкатенацией.
- **XSS:** `HtmlUtils.htmlEscape` экранирует логин в ответе регистрации и текст заметок при чтении. В БД хранится исходный текст. Ошибки не отражают ввод; ответы имеют тип JSON, заголовок `nosniff` и CSP `default-src 'none'`.
- **Пароли:** сохраняются только bcrypt-хэши с индивидуальной солью и cost=12. При регистрации пароль должен содержать минимум 12 символов и не превышать 72 байта UTF-8; некорректный ввод возвращает `400`.
- **JWT:** после входа выдаётся токен HS256 на 15 минут. Spring Security проверяет подпись, алгоритм, срок действия, `iss`, `aud` и `sub`. Пароль в токен не включается. Ключ берётся из `app.jwt-secret`.
- **Доступ:** заметки выбираются только для владельца из проверенного `sub`. Регистрация и вход публичные. Сессии и cookie-аутентификация не используются, поэтому CSRF отключён для этого Bearer API. Для развёртывания требуется HTTPS.
